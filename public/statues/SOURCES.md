# 성상 이미지 출처

신상·성상은 사용자가 직접 구한 이미지를 우선 쓴다. AI 생성(scripts/statues/regen.mjs)은 구한 이미지가 없을 때만 쓰는 예비 방법이다.
새 이미지를 넣을 때마다 아래 표에 출처와 사용 조건을 적는다. 공개 서비스이므로 상업적 이용이 가능한지 확인한다.

| 파일 | 상 | 쓰는 곳 | 구한 사람 | 출처 | 사용 조건 |
|---|---|---|---|---|---|
| buddha.png | 석가모니불 좌상(항마촉지인) | 대웅전 | 사용자 | (확인 필요) | (확인 필요) |
| mary.png | 성모상(흰 석고) | 대성당 성모 제대, 본당, 성모 동산 | 사용자 | (확인 필요) | (확인 필요) |
| crucifix.png | 십자고상 | 대성당·본당 제대 | 아직 없음 | | |
