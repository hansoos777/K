# 벌레 박살

바퀴벌레·모기·파리·개미·거미·지네를 여러 무기로 잡으며 스트레스를 푸는 PWA 게임입니다.
벌레 모습을 **귀여움 → 만화 → 리얼** 세 단계로 고를 수 있고, 단계별로 조금씩 진짜 같아지는
**공포 극복 코스**(7단계)가 있습니다.

빌드 과정이 없는 정적 파일(ES 모듈)입니다. 소리는 Web Audio로 합성하고 그림은 전부 캔버스로 그려서
이미지·음원 파일이 없습니다(아이콘 제외). 기록은 이 기기의 localStorage에만 저장합니다.

## 모드

| 모드 | 내용 |
|---|---|
| 자유 모드 | 시간 제한 없음. 오른쪽 도구로 벌레 부르기(종류별, 바퀴벌레 떼), 바닥 청소, 깨진 유리 갈기 |
| 60초 도전 | 점점 많이·빠르게 나옴. 오래 두면 화면 밖으로 도망감. 등급(S~C)과 스트레스 해소 % |
| 공포 극복 코스 | 귀여운 개미 → 귀여운 바퀴 → 모기·파리 → 거미 → 리얼 바퀴 → 지네 → 바퀴 대발생 |

일시정지하면 화면이 흐려집니다(무서울 때 바로 가릴 수 있게).

## 무기와 효과

| 무기 | 쓰는 법 | 효과 |
|---|---|---|
| 손바닥 | 톡 | 손이 내려와 찰싹, 빠른 연타 |
| 파리채 | 톡 | 휘두르는 잔상, 날벌레에 2배, 터진 자리에 그물 자국 |
| 전기채 | 누르고 휘두르기 | 그물에 닿으면 전기 아크·불똥·지지직, 새까맣게 탐 |
| 슬리퍼 | 톡(던지기) | 돌면서 날아가 퍽, 미끄러지며 멈춤 |
| 밟기 | 톡 / 꾹 누르기 | 운동화가 콱, 누르고 있으면 비벼 밟아 얼룩이 번짐, 바닥 무늬 자국 |
| 두꺼운 책 | 톡 | 넓은 범위, 먼지 폭발, 큰 흔들림 |
| 망치 | 톡 | 가장 셈, **화면 유리가 거미줄처럼 깨짐**, 유리 파편 반짝임 |
| 살충제 | 누르고 뿌리기 | 안개가 퍼지고, 벌레가 비틀대다 뒤집혀 버둥거리다 멈춤 |
| 화염방사기 | 누르고 끌기 | 불길·바닥에 남는 불·그을음, 불붙은 벌레가 날뛰다 숯이 됨, 옆 벌레로 번짐 |

벌레마다 행동이 다릅니다. 바퀴벌레는 벽을 따라 달리다 멈추고 충격에 도망가며(리얼 모드에서는 가끔 날아오름),
모기는 사람(포인터) 쪽으로 다가오고, 파리는 앉아서 앞발을 비비다 무기가 오면 피하고, 개미는 줄지어 걷고,
거미는 천장에서 실을 타고 내려오며, 지네는 마디가 물결칩니다. 바퀴벌레·거미·지네는 질겨서 약한 무기에는 한 번 버티고
절뚝이며 체액을 흘립니다. 피 빤 모기(배가 빨간 모기)를 잡으면 빨간 피가 튑니다.

단축키(PC): 숫자 1~9 무기 바꾸기, Esc 일시정지.

## 실행

```bash
cd games/bugsmash
python3 -m http.server 8080     # 또는 npx serve .
# http://localhost:8080 열기
```

서비스 워커는 http(s)에서만 동작합니다. 파일을 바로 여는 file:// 에서는 설치·오프라인이 안 됩니다.

## 배포 (Cloudflare Pages)

자동: `games/bugsmash/`가 바뀐 채로 `main`에 올라오면 `.github/workflows/deploy-bugsmash.yml`이
Cloudflare Pages `bugsmash` 프로젝트(https://bugsmash.pages.dev)에 올립니다. 믿어보까 배포와 같은 GitHub 비밀값
`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`를 씁니다. GitHub → Actions → "Deploy 벌레 박살" → Run workflow로 직접 돌릴 수도 있습니다.
Cloudflare 비밀값이 없으면 대신 GitHub Pages(https://hansoos777.github.io/K/)에 올립니다.

손으로 올릴 때:

```bash
npx wrangler pages deploy games/bugsmash --project-name bugsmash --branch main
```

어느 정적 호스팅이든 이 폴더를 그대로 올리면 됩니다(GitHub Pages, Netlify 등). 하위 경로에 올려도 동작하도록
모든 경로를 상대 경로로 썼습니다. 파일을 고친 뒤에는 `sw.js`의 `VERSION`을 올려 주세요.

## 파일

| 파일 | 내용 |
|---|---|
| `js/main.js` | 게임 흐름, 모드, 입력, 점수, 그리기 순서 |
| `js/bugs.js` | 벌레 종류·행동·피해·죽는 방식(터짐·탐·감전·독) |
| `js/art.js` | 벌레 그림(종류 6 × 모습 3, 납작·뒤집힘·숯 자세) |
| `js/weapons.js` | 무기 동작과 판정 |
| `js/gear.js` | 무기 그림 |
| `js/fx.js` | 입자, 바닥 자국, 유리 금, 글자 팝업 |
| `js/bg.js` | 바닥(나무 마루·주방 타일·컴퓨터 화면) |
| `js/audio.js` | 합성 효과음·지속음(모기 윙~, 살충제 칙~, 불 화르륵) |
| `js/ui.js` | 화면 마크업 |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA |
